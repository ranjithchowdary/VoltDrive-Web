# Changelog

## 1.0.0-web

- Added a separate browser application for Customer, Station Owner and Admin roles.
- Added JDK REST backend, session authentication, PBKDF2 password hashing and role checks.
- Added PostgreSQL schema and Render Blueprint/Docker deployment files.
- Added responsive dashboard, station management, booking capacity checks and admin reports.
- Added bundled VoltDrive icons/fonts, browser location map and OSRM route support.
- Added local setup, demo accounts, GitHub and Render instructions.
